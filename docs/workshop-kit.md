# Начните здесь

Откройте проект в Codex, Claude Code или Cursor либо используйте подготовленный Python-запуск. Выберите один вариант — выполнять задания во всех программах не нужно.

Если ноутбук ещё не подготовлен, откройте [инструкцию подготовки](participant-prework-draft.md). При проблеме покажите ведущему команду и ошибку; файлы с ключами и доступом к кластеру отправлять не нужно.

## Что будем делать

Первый час — знакомство и запуск подготовленного окружения. Затем 30 минут перерыв и час практики. Время ниже считается от начала практики.

| Время | Задание | Что вы сделаете |
|---|---|---|
| 0–8 | [Найдите ошибку в ответе агента](../workshop/exercises/investigation_audit/README.md) | Сверите вывод с данными |
| 8–20 | [Сделайте ответ удобнее для проверки](../workshop/exercises/skill_revision/README.md) | Измените инструкцию и сравните ответы |
| 20–35 | [Дайте агенту доступ к Kubernetes](../workshop/exercises/mcp_connection/README.md) | Подключите MCP и проверьте объяснение ошибки |
| 35–55 | [Найдите логи нужного запроса](../workshop/exercises/trace_to_logs/README.md) | Допишете функцию и дадите агенту её использовать |
| 55–60 | Завершение | Сохраните результат и оставшиеся вопросы |

Открывайте карточки по порядку. Внутри есть нужные файлы, команды и готовые запросы для чата.

## Перед первой командой

Все команды выполняются из корня проекта — там находятся папки `workshop/` и `fixtures/`. Активируйте подготовленное окружение.

macOS/Linux:

```bash
source workshop/.venv/bin/activate
```

Windows PowerShell:

```powershell
workshop/.venv/Scripts/Activate.ps1
```

Если активация недоступна, заменяйте `python` в командах на `workshop/.venv/bin/python` (macOS/Linux) или `workshop/.venv/Scripts/python.exe` (Windows). Политику PowerShell менять не нужно.

## Как сохранять работу

Создайте папку `workshop/.local/`. Сохраняйте туда заметки и ответы, как указано в карточках. Код можно писать с агентом, но его ответ проверьте по исходным данным сами.

При затруднении попросите подсказку. Готовые решения и резервные ответы выдаёт ведущий; заранее добавлять их в чат не нужно. Если используете готовый пример, запишите, какую часть сами ещё не проверили.

На практике меняем только инструкцию и свою функцию, указанные в карточках. Код Boutique/order-worker, проверки и состояние стенда не меняем.
