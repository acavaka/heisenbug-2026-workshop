# QAI: начало работы участника

Формат: 60 минут вводной и настройки → 30 минут перерыв → 60 минут практики.
Работайте в привычном Python-харнессе, Codex, Claude Code или Cursor.

1. До занятия выполните [prework](participant-prework-draft.md).
2. На практике проходите [четыре задания](workshop-exercises-draft.md) по порядку.
3. После занятия используйте [руководство переноса](monday-replay-guide.md).

| Время | Задание |
|---|---|
| 0–8 | [Проверить расследование](../workshop/exercises/investigation_audit/README.md) |
| 8–20 | [Улучшить инструкцию](../workshop/exercises/skill_revision/README.md) |
| 20–35 | [Подключить MCP](../workshop/exercises/mcp_connection/README.md) |
| 35–55 | [Реализовать trace_to_logs](../workshop/exercises/trace_to_logs/README.md) |
| 55–60 | Разобрать доказанное, неизвестное и следующий шаг |

Подсказку запросите у ведущего после своей попытки. Решения и резервные результаты
хранятся отдельно; не подключайте их в контекст агента. Код разрешено писать с агентом,
но результат проверяете вы. Сохраняйте свою работу в workshop/.local/.

Модель выбирает роли и досбор. Python принимает вердикт через runtime, редакторы — через
реальный qai_validate соответствующего MCP. Общий формат и происхождение цитат не заменяют
проверку причинности. Приватный behavioral eval в публичном запуске не выполняется.

Application MCP готовится заранее, k8sgpt подключаем в задании 3. После изменения correlate
перезапустите application MCP и создайте новое investigation_id. Каталоги не смешивайте.
Boutique, order-worker, валидаторы и стенд на практике не меняем.
