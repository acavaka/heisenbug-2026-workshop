# Подготовка Windows: согласовать заранее

Текущий USB-комплект содержит macOS arm64 wheels, бинарники и установщики.
Проверенного offline-маршрута для Windows в этом выпуске нет.
Не используйте macOS-инструменты или скопированный venv на Windows.

Начните с [prework](participant-prework-draft.md) и заранее сообщите ведущему ОС/CPU.
Варианты: отдельно подготовленное и проверенное до занятия окружение либо работа в паре
на готовом ноутбуке. Для самостоятельной подготовки нужны совместимые Docker/виртуализация,
Python, wheels, Kind/kubectl/k8sgpt и полный набор образов; этот документ не обещает их установку
из текущей флешки. Установку и подбор версий в практические 60 минут не включаем.

Карточки общие для всех хостов. Файловый replay позволяет разбирать данные без Kubernetes,
но не засчитывает live-интеграцию k8sgpt. Подготовьте выбранный редактор и авторизацию модели.
