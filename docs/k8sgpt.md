# k8sgpt на воркшопе

Основное задание теперь использует **MCP**: [подключение, проверка и контракт](k8sgpt-mcp.md).
Участники работают в Python-харнессе, Claude Code, Codex или Cursor с общими критериями.
Учебный namespace — `qai-training`; Boutique и order-worker не меняем.

Старый скилл `k8sgpt_analyze` остаётся для совместимости с CLI-режимом, когда QAI_MCP_CONFIG
не задан. При явном MCP-подключении он исключён из Python investigator, автоматического
fallback нет. CLI-вызов не засчитывается как выполнение задания на MCP.

Прежнее упражнение с поломкой paymentservice в Boutique исключено из текущего плана.
Подготовлены отдельный неисправный учебный сервис и read-only RBAC:
Профиль доступа выдаёт ведущий. Локальный синтетический MCP replay
сохранён как независимый режим без доступа к кластеру.
