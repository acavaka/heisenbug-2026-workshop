# Практика с агентом — 60 минут

Единая точка входа: [готовый комплект](workshop-kit.md).


| Минуты | Задание | Результат |
|---|---|---|
| 0–8 | Проверить расследование | Факты, пробел или ложный вывод, следующий запрос |
| 8–20 | Улучшить скилл/инструкции | Изменение и сравнение на тех же данных |
| 20–35 | Подключить k8sgpt через MCP | Реальный вызов инструмента и инфраструктурные доказательства |
| 35–55 | Новый скилл trace_to_logs | Реализация, проверки, вызов агентом |
| 55–60 | Разобрать ограничения | Что доказано, что осталось неизвестным |

Первая часть — 60 минут знакомства, настройки и проверки; затем перерыв 30 минут.
Один маршрут для Python, Claude Code, Codex и Cursor.

Карточки открывайте по порядку; подсказки выдаёт ведущий после самостоятельной попытки.
Все команды выполняются из корня репозитория. Перед практикой активируйте уже созданный venv:
macOS/Linux — `source workshop/.venv/bin/activate`, PowerShell —
`workshop/.venv/Scripts/Activate.ps1`. Если активация PowerShell запрещена политикой,
вместо `python` используйте `workshop/.venv/Scripts/python.exe`; политику менять не нужно.
На macOS/Linux без активации используйте `workshop/.venv/bin/python`.
Пакеты устанавливаются заранее, не в 60 минут практики.

1. [Проверить расследование — 8 минут](../workshop/exercises/investigation_audit/README.md).
   Сохранённый ошибочный ответ, ручная сверка источников; модель и стенд не нужны.
2. [Улучшить общую инструкцию — 12 минут](../workshop/exercises/skill_revision/README.md).
   Одна правка формата проверки утверждений, одинаковые входы до/после. Уже корректный
   baseline допустим: не заставляем модель ошибаться ради упражнения.
3. [Подключить k8sgpt через MCP — 15 минут](../workshop/exercises/mcp_connection/README.md).
   Настройка выбранного хоста, фактические вызовы агентом, проверка вердикта.
   Сервис и read-only доступ заранее подготовлены. Replay явно отмечается как резерв,
   не как успешная проверка live k8sgpt.
4. Полная новая [карточка trace_to_logs](../workshop/exercises/trace_to_logs/README.md):
   healthy pods, ошибочная сумма checkout, связанный trace, чужой ERROR и доступный код.
   Это файловый replay, не продолжение live-наблюдения того же Pod.
5. Сравните infrastructure vs application: здоровый Pod не исключает бизнес-баг;
   соседняя строка по времени не доказывает принадлежность запросу.

Расширения для быстрых участников указаны в карточках; дополнительную подсказку запросите у ведущего.
После занятия: [повторить на своём проекте](monday-replay-guide.md).

Подсказки, ответы и контрольные точки ведущий хранит отдельно. Результаты сохраняются в workshop/.local.
Второе задание в редакторе проверяет одну роль на файлах, в Python — полный replay;
это общая учебная рубрика, не сравнение производительности хостов.
Тайминг — бюджет, который ещё нужно подтвердить репетицией группы: особенно два LLM-запуска
и самостоятельное подключение MCP. На границах 8/20/35 минут переходим к следующему заданию;
незавершённые проверки отмечаем, не выдаём за успешные.
