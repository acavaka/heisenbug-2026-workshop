# Подготовка macOS

Актуальная инструкция: [prework](participant-prework-draft.md) →
[пошаговая установка с USB](new-macbook-offline.md).

Подготовленный offline-набор рассчитан на Apple Silicon и Python 3.12.6.
Проверен запуск на установленном Docker 4.42.1; установка приложенного Docker 4.91.0/VMM
на чистом Mac не подтверждена. Для macOS Intel нужен отдельно подготовленный маршрут.

Получите весь публичный комплект: ZIP участника, wheels, tools, images, installers
и контрольные суммы. Одного клона репозитория или архива исходников недостаточно.
Новый стенд запускается строгим workshop/offline/launch.py по USB-инструкции;
существующий кластер повторно не создавайте. MCP и выбранную модель подготовьте заранее.
