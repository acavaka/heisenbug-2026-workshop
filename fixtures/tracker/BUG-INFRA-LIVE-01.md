# BUG-INFRA-LIVE-01 — checkout-probe не запускается в учебном namespace

Источник: живой учебный стенд, namespace `qai-training`, Deployment и Service `checkout-probe`.
Сценарий намеренно создан для воркшопа; данные синтетические, состояние Kubernetes реальное.
Наблюдаемое поведение: после развёртывания контейнер `app` не стал Ready; запросы к
учебному сервису не могут обслуживаться. Ожидание: контейнер стартует и отвечает на HTTP :8080.
Исследуем текущий запуск: время начала взять из creationTimestamp текущего Pod; сравнить с events.
Имя Pod и UID заранее неизвестны — найти по label `app=checkout-probe`.

Задача: установить причину, собрать конфигурацию и связанные события, указать направление
исправления и ограничения. Разрешена только диагностика через подключённый MCP k8sgpt
с read-only доступом к qai-training. Исправление на стенде не выполняется.
Boutique, order-worker и namespaces вне qai-training к этому инциденту не относятся.
Сведения о бизнес-поведении после успешного старта пока отсутствуют.
