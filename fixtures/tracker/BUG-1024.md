# BUG-1024: Цена на странице товара ≠ сумма в корзине после уценки

- **Приоритет:** High
- **Статус:** Open
- **Компонент:** productcatalogservice / frontend / cart
- **Сервис:** Online Boutique (Kind)
- **Автор:** support-team
- **Создан:** 2026-09-16 11:42

## Описание

После уценки товара **Sunglasses** (`product_id=OLJCESPC7Z`) на странице
товара отображается новая цена (~$15.99), но в корзине по-прежнему старая
(~$19.99). Воспроизводится нестабильно; через некоторое время (около часа)
проблема «сама» исчезает.

## Шаги воспроизведения

1. Открыть http://127.0.0.1:8080/product/OLJCESPC7Z — цена новая.
2. Добавить товар в корзину и открыть /cart — сумма со старой ценой.
3. Подождать ~1 час — корзина начинает показывать новую цену.

## Ожидаемый результат

Цена на витрине и в корзине совпадают сразу после уценки.

## Фактический результат

Корзина держит старую цену. Затронуты товары, у которых недавно меняли цену.

## Дополнительно

- Уценка выполнялась через workshop admin API catalog-сервиса.
- Промокоды не применялись.
- Полезные направления: логи `productcatalogservice` (`cache hit` / `cache miss` /
  `price updated`), код `GetProduct` vs `ListProducts`, frontend product page vs cart.
