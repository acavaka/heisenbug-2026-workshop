# INC-2088: Двойные списания при оплате заказов

- **Приоритет:** Critical
- **Статус:** Investigating
- **Компонент:** payments
- **Версия:** 2.14.0
- **Автор:** oncall-sre
- **Создан:** 2026-06-30 19:08

## Описание

С ~18:40 участились обращения о двойном списании средств за один заказ.
Платёжный шлюз подтверждает: по ряду заказов проведено по два успешных
платежа с разными request_id.

## Что известно

- Релиз 2.14.0 выкачен сегодня в 18:20.
- В 18:35–19:05 у платёжного шлюза наблюдалась деградация (медленные ответы).
- Двойные списания есть НЕ у всех платежей — только у части.
- Пример: заказ ORD-a3f81c02, пользователь u-77012, списано дважды по 7 490 ₽.

## Задача

Найти root cause и предложить исправление. Логи приложения за окно
инцидента приложены (logs/app-2026-06-30.log, logs/payments-2026-06-30.log).
